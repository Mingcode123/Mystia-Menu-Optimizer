# 验证方法与结果

验证分为文件一致性检查、受控输入下的输出对照和完整工作簿的代表性运行案例。各类证据分别回答文件是否相同、特定条件下的输出是否一致，以及所测使用流程是否完成。

## 文件一致性

| 范围 | 方法 | 已观察结果 |
| --- | --- | --- |
| Python 源码 | 逐文件比较 11 个 `.py` 文件与作者提供的基准文件 | 字节内容与 SHA-256 均一致 |
| 网页源码与资源 | 比较 HTML、SheetJS、图标映射和 PNG | 224 个文件一致：1 个 HTML、2 个 JS、221 张 PNG；入口文件名由 `INDEX.html` 改为 `index.html` |
| 输入工作簿 | 比较完整 XLSX 文件的字节内容及 SHA-256 | 13 张表及其公式、缓存值、图片、Icon 字段、格式和元数据完整保留 |

网页基准 HTML 的 SHA-256 为 `1492bf31f1ca7cd11c2b718ba32a897cae7862ad5f049c5a4ecf831691df029a`。

工作簿原件与发布文件的 SHA-256 均为 `5c1a1ef52ce6594a2ca6cc90c8e10aff2d4dd40ac32928789dee9ea9a027a16f`。来源、文件大小和工作表规模见[文件审计](../data/workbook-provenance.json)。文件一致性检查验证分发内容与基准相同，数据与公式的有效性另受[数据来源说明](data-provenance.md)中的条件限制。

## Python 受控输出对照

对照入口为 `singlePLAN_cover3_mixIng_nCookware.py`。作者提供的脚本与发布副本使用同一组测试数据和交互输入，分别执行显式输出路径与自动命名两种模式，共四次运行。

| 项目 | 设置 |
| --- | --- |
| 运行环境 | Python 3.12.14、openpyxl 3.1.5 |
| 数据规模 | 12 种食材、8 道料理、3 位顾客、5 种厨具、12 条供给记录 |
| 交互输入 | 流行喜爱与流行厌恶均为空；厨具数量为 3 |
| 其他参数 | 最低分为 3；每客日订单量为 5 |
| 路径条件 | 显式模式使用绝对输入和输出路径；自动命名模式使用隔离目录 |

四次运行均完成，三位顾客均产生方案。比较时排除 XLSX 容器时间戳，并规范化 `docProps/core.xml` 中的创建与修改时间；其余 ZIP 成员内容一致。比较范围包括单元格值、样式、合并范围、列顺序、列宽、行高和冻结窗格。

输出均为 `Plans` 工作表、14 列、4 行（含表头），冻结位置为 `A2`。图标列为空占位，顾客图标列宽为 `10.64`，数据行高为 `59.7`。自动命名模式的文件名及相对输出目录一致。该对照覆盖指定输入与两种输出路径。

## 完整工作簿网页运行

通过本地 HTTP 服务加载仓库中的完整工作簿，执行以下操作条件：

| 参数 | 取值 |
| --- | --- |
| 稀客 | 博丽灵梦 |
| 最低得分 | 3 |
| 加料子集过滤 | 开启 |
| 等价食材去重 | 开启 |
| 流行、必含与排除标签 | 空 |
| 结果搜索 | “饭团” |

工作簿自动加载成功，角色头像正常显示。计算生成 4,372 条候选，搜索后显示 59 条。导出的 XLSX 包含一个 `结果` 工作表、60 行（含表头）和八列：

```text
售价,得分,料理,cookware,总食材数,基础食材,加料,最终tag
```

另有四组边界输入对照，涉及配方禁忌、TDQ 等价替换、重复等价加料权重及零售价标签，观察到作者提供的实现与发布实现结果一致。对应的触发条件与实际行为见[网页指南](web-guide.md)。

## 适用范围与未覆盖项

- `nCookware` 使用真实 58 客数据、空流行和三种厨具的运行于 60 秒后超时终止，未获得完整输出。全量输出对照与总运行时间尚未测得。
- 受控 Python 对照和网页案例提供特定输入下的运行证据；其结果未覆盖全部 PLAN 分支、异常输入和游戏条件。
- 跨浏览器兼容性、跨设备性能及不同数据规模下的耗时尚未系统测量。
- 现有验证未包含完整经营收益实验、共享库存约束验证或全局最优性证明。

上述结论限于当前分发文件及所列运行条件。算法候选范围与数据不确定性分别见[设计说明](design.md)和[数据来源说明](data-provenance.md)。

## 复现口径

复现比较应固定工作簿、程序入口、最低分、订单量、流行条件和厨具条件。Python 输出比较还涉及交互、文件名、工作表、列顺序、合并区域、尺寸、喜好命中分隔、食材排序及无解行。XLSX 文件包含时间元数据，比较计算结果与排版时需单独处理这些时间字段。

各入口的操作命令和输出位置见[输入输出说明](input-output.md)。各脚本的优化目标与已知候选限制见[设计说明](design.md)。
