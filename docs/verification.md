## 未完成及证据边界

- 原 `nCookware` 的真实 58 客全量运行在 60 秒后停止，本轮尚未完成全量输出对照。
- 小规模测试输入用于原件与副本的同条件比较，不是公开游戏收益实验，也不证明全部合法具体食材组合的全局最优。
- 网页边界对照证明保留了原行为，不代表相应禁忌、阈值、停止或导出问题已修复。具体限制见[网页指南](web-guide.md)。
- 原程序对异常数据的全部分支、全部 PLAN 版本的全量输出、所有浏览器及跨设备性能尚未全面覆盖。
- 没有完整采样记录、实际经营收益对照或共同库存验证。

此前重构版本的 31 项 Python 测试、13 项网页测试、JSON／CSV 结果和独立穷举结论不作为本版原程序的验证结果。公开包不依赖该重构的测试或 CI 体系。

## 复现口径

使用同一工作簿、同一入口、相同最低分与订单量、相同流行和厨具回答比较。对 Python 除目标结果外还应核对交互、文件名、工作表、列顺序、合并区、尺寸、喜好命中分隔、食材排序及无解行。XLSX 容器有时间元数据，不能只以整个文件哈希不同认定结果变化。

原入口的操作命令和输出位置见[输入输出说明](input-output.md)。各脚本的优化目标与已知候选限制见[设计说明](design.md)。
