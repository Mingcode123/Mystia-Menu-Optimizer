# 数据来源与运行工作簿

## 原工作簿

根目录 [东方夜雀食堂.xlsx](../东方夜雀食堂.xlsx) 直接复制作者最初提供的完整文件，与原件逐字节一致。工作簿共 13 张表，其中程序使用以下七张输入表：

```text
稀客、普客、料理、食材、酒水、食材merchant_data、酒水merchant_data
```

工作簿还保留五张图像映射表和 `Sheet1`，原公式、已保存的计算结果、格式、图片、Icon 字段和文件元数据均未清洗或重写。网页显示图片仍由原独立资源目录提供。

发布整理**不修正采购价、不替换供给值、不重算期望、不改写 Owned**，也不将公式替换成数值。各原脚本继续按自己的规则解释工作簿。来源、原件与发行文件 SHA-256 及表规模见 [workbook-provenance.json](../data/workbook-provenance.json)。

当前一致性核对以整个 XLSX 文件的 SHA-256 相同为准，覆盖公式、缓存与容器内其他内容。原 `nCookware` 读取其中的 62 条食材记录、164 道料理记录（其中 163 道持有）、58 位稀客及 62 条供给记录。文件一致性不等同于所有游戏事实正确或所有脚本已完成全量运行；详细验证范围见[验证记录](verification.md)。

## 价格期望与日供给

历史价格整理采用过数量加权口径：渠道单位价为 $`p_i`$、对应数量为 $`q_i`$ 时，估计单位采购价为：

```math
\bar p=\frac{\sum_i p_iq_i}{\sum_i q_i}
```

这一表达要求总数量非零，且分子、分母采用相同来源口径。委托数量若进入分母但没有相应现金支出项，就相当于在该口径中按零采购现金处理，仍没有计算时间和机会成本。它是历史数据处理假设，不是完整经济成本。

部分历史食材采购价按行号引用商贩表，而两表排序不同，存在关联错位风险。当前工作簿保留原公式及缓存值，不把这些值静默替换成按名称修正的结果。独立利润报表因此应结合数据口径审阅；PLAN 的主要比较量仍是喜好覆盖、食材件数和供给余量，不能将件数解释为采购金额。

`Total Daily Quantity` 是日供给经验记录，不是玩家当前库存，也不是每天必定获得的数量。逐客余量用 $`q_i-Kc_i`$ 表达假设需求后的压力，允许负值，不包含其他顾客的联合消耗。

## 工作簿输入结构

<a id="workbook-schema"></a>

网页及 PLAN 系列主要使用以下四表。其他菜单和利润脚本还使用普客、酒水及酒水供给资料。

| 表名 | 常见原字段 |
| --- | --- |
| `食材` | `Name`、`Tags`、`Buy Price`、`Level` |
| `料理` | `Name`、`Tags`、`Cookware`、`Sell Price`、`Required Ingredients`、`Forbidden Ingredients`、`Owned` |
| `稀客` | `Name`、`Type`、`Preferred Tags`、`Disliked Tags`、`Budget` |
| `食材merchant_data` | `Name`、`Total Daily Quantity`、`Average Buy Price` |

这些是原字段示例，不是新增的严格校验协议。原网页、PLAN 解析器与类菜单对别名、空行、默认值和类型的处理各不相同。`nCookware` 支持稀客空姓名续行；网页按原 Type 条件筛选。自有文件应以根工作簿和选定脚本为参照，不使用结果工作簿作为源数据。

追加或基础用量中的重复食材仍以重复名称表示。程序读取已保存的单元格结果，不承担 Excel 公式计算。修改公式或其输入后，应先在支持这些公式的电子表格软件中重算并保存；只保留数值会丢失后续随输入重算的能力，因此当前发布直接保留完整原文件。保留公式也不能补回当年未保存的采样日期和次数。

## 图片与私人材料

[HTML/icon_map.js](../HTML/icon_map.js) 把名称映射到 [HTML/izakaya_icons_pack/](../HTML/izakaya_icons_pack/) 下的 58 张稀客头像和 163 张料理图片。它们与工作簿数值分开维护，不进入供给或评分计算。原 Python 的 `Name Icon`、`Dish Icon` 输出列为空占位，不自动嵌入这些资源。

完整原工作簿随包提供。独立的历史利润表、带图规划表、原始聊天、完整游戏资料与备份留在本地。公开审计记录原件复制与文件一致性，不是新的规划输入或自动修复器。源工作簿与输出的关系见[输入输出说明](input-output.md)。
